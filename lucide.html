CMS Lucide

Lucide is a lightweight static-site content editor. The repository includes PHP components (login and AJAX editing), so it needs a PHP-enabled web server. GitHub Pages only serves static files and cannot run its PHP backend; embedding it here as a working editor would therefore leave its editing functions unavailable.
